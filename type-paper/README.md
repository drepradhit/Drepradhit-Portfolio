# 📝 Type Paper

**Type Paper** is a minimalist typing experience crafted for speed and focus. Inspired by the tactical feel of vintage typewriters and modern productivity tools, Type Paper offers a distraction-free environment to hone your typing skills.

## ✨ Features

- **Tactile Paper Aesthetic**: A warm, parchment-inspired UI that reduces eye strain and increases focus.
- **Precision Tracking**: Real-time WPM (Words Per Minute) and Accuracy metrics.
- **Smooth Animations**: Caret and character transitions powered by Framer Motion.
- **Sub-Zero Latency**: Built on Next.js 15 for the fastest possible response times.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

1. `cd type-paper`
2. `npm install`
3. `npm run dev`
